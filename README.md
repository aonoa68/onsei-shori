## 進化の視点（2026-09-17 追加）

全14回の `lecture.md` に「## 進化の視点」の節を1つずつ入れた。**その回の技術に直接つながる進化・生物学の話**を置き、最後に学生への問いで閉じる形にしてある。

例：第2回は喉頭下降説の再検討（Fitch ほか 2016／Boë ほか 2017・2019）からソース・フィルタモデルへ、第5回は蝸牛の分解能からメル尺度へ、第7回は乳児の統計学習（Saffran ほか 1996）から自己教師あり学習へ、第10回は会話の間の言語横断研究（Stivers ほか 2009）から応答遅延の設計へ。

引用した文献は、書き込む前に書誌を確認済み。

## ページの作り直し

`../第NN回/lecture.md` を編集したら、次を実行してから確認する。冒頭の資料リンクの枠を付け直し、重複する見出し行（科目名・担当・形式など）を落とす。

```bash
python3 build_pages.py
mkdocs serve
```

> **注意（2026-10-20）**：`build_pages.py` は14回ぶん全部を上書きする。第3〜9回の `docs/sessions/NN.md` には、
> `lecture.md` に無い追記（導出の折りたたみなど）が入っているため、全体を再生成すると消える。
> 1回分だけ直したいときは、実行後に `git checkout -- docs/sessions/` で他の回を戻すこと。

## 手元で見る

```bash
cd course_site
mkdocs serve      # http://127.0.0.1:8000 で開く
```

スライドを作り直すとき（`../第NN回/slides.md` を編集したあと）：

```bash
cd ..
marp "第04回/slides.md" -o course_site/docs/slides/04.html --html
```

`--allow-local-files` は付けない。付けると変換が終わらない。

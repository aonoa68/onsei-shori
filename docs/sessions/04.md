## 進化の視点：スペクトログラムは、内耳の模倣である

周波数を分解して時間軸に並べるという発想は、工学の発明である前に**内耳の構造**である。蝸牛は基底膜の場所ごとに共振する周波数が違い、音を場所の分布に変換している。哺乳類に広く共通する仕組みで、スペクトログラムはその働きを数値で再現したものだといえる。

もう一つ、フォルマントには**体の情報**が乗る。声道が長いほど共鳴周波数の間隔は狭くなる。アカゲザルで、フォルマントの平均間隔（formant dispersion）が声道長と体サイズによく対応することが示されている（Fitch 1997, *JASA*）。

**技術への接続**：話者によってフォルマントがずれるのは、体格差がそのまま音に出るためである。音声認識では**話者正規化**（声道長正規化）でこの差を吸収する。つまり、生物音響学が「体の大きさの手がかり」として扱う量を、工学は「消すべき雑音」として扱っている。

**問い**：同じ量が、ある分野では信号で、別の分野では雑音になる。この授業で他にそういう量はあるか。

### スライド1: 音とは何か？—「音はサイン波の重ね合わせ」

**直感的理解から始めよう**

自然界の音はどんなに複雑でも、**単純なサイン波（正弦波）の足し算**で表せます。

例えばピアノの「ラ（440Hz）」は：
- 基音：440Hz のサイン波（一番大きい）
- 倍音：880Hz のサイン波
- 倍音：1320Hz のサイン波
- …（高次の倍音が続く）

これらを合算すると、あのピアノらしい音色になります。

**アナロジー：光とプリズム**

> 白色光をプリズムに通すと、赤・橙・黄・緑・青・藍・紫に分かれる。
> 音をフーリエ変換すると、音を構成する周波数（音程）の成分に分かれる。

$$
x(t) = A_1 \sin(2\pi f_1 t) + A_2 \sin(2\pi f_2 t) + A_3 \sin(2\pi f_3 t) + \cdots
$$

### スライド2: DFT（離散フーリエ変換）の計算方法

**連続 → 離散へ**

コンピュータは連続信号を扱えないため、一定間隔でサンプリングされたデジタル信号（離散信号）を処理します。

**DFTの定義式**

$$
X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-j \frac{2\pi}{N} k n}, \quad k = 0, 1, \ldots, N-1
$$

- $x[n]$：時間領域の離散信号（$N$個のサンプル）
- $X[k]$：周波数領域の複素数（$k$番目の周波数成分の大きさと位相）
- $|X[k]|$：振幅スペクトル（その周波数の強さ）

**直感的な意味**

$X[k]$ は「信号の中に $k$ 番目の周波数成分がどれだけ含まれているか」を測る。

対応する周波数：$f_k = \frac{k \cdot f_s}{N}$（$f_s$：サンプリング周波数）

???+ note "導出①：DFT は「その周波数の波と、どれだけ似ているか」を測っている"

    オイラーの式 \( e^{-j\theta} = \cos\theta - j\sin\theta \) を定義式に入れると、

    $$ X[k] \;=\; \sum_{n=0}^{N-1} x[n]\cos\!\left(\frac{2\pi k n}{N}\right) \;-\; j \sum_{n=0}^{N-1} x[n]\sin\!\left(\frac{2\pi k n}{N}\right) $$

    右辺に現れるのは、どちらも **和の形の掛け算**である。信号を \( N \) 個の数を並べたベクトル \( \boldsymbol{x} \) と見て、同じ長さのベクトル

    $$ \boldsymbol{c}_k = \left[\cos\frac{2\pi k \cdot 0}{N},\; \cos\frac{2\pi k \cdot 1}{N},\; \dots \right], \qquad \boldsymbol{s}_k = \left[\sin\frac{2\pi k \cdot 0}{N},\; \sin\frac{2\pi k \cdot 1}{N},\; \dots \right] $$

    を用意すれば、実部は \( \boldsymbol{x}\cdot\boldsymbol{c}_k \)、虚部は \( -\,\boldsymbol{x}\cdot\boldsymbol{s}_k \) にほかならない。**DFT は、信号と「周波数 \( k \) の波」との内積を、\( k \) を変えながら並べたものである。**

    内積は「2つのものがどれだけ同じ向きを向いているか」を測る量である。統計学Ⅰ第5回の相関係数も、標準化した2変数の積の和として同じ形をしている。**似ている度合いを積の和で測る**という発想は共通している。

    余弦と正弦の**両方**と内積を取るのはなぜか。信号の位相がずれていると、余弦だけとの内積はたまたま 0 になりうる。そのとき正弦との内積が大きくなる。2つを組にして

    $$ |X[k]| = \sqrt{(\boldsymbol{x}\cdot\boldsymbol{c}_k)^2 + (\boldsymbol{x}\cdot\boldsymbol{s}_k)^2} $$

    とすれば、**位相がどこにあっても、その周波数成分の強さだけを拾える**。スペクトログラムが位相を捨てて \( |X[k]| \) だけを描けるのは、この形になっているからである。

    !!! note "$k$ と周波数の対応"
        \( \boldsymbol{c}_k \) は \( N \) 点の区間にちょうど \( k \) 周期入る波である。区間の長さは \( N/f_s \) 秒なので、その周波数は \( k \div (N/f_s) = k f_s / N \)。上の \( f_k \) の式はここから出ている。

    ここで示したのは「DFT が何を計算しているか」までである。**どんな信号もこの形に分解し切れる**（完全性）ことや、連続信号のフーリエ変換が収束する条件は、この授業で扱う数理の範囲外である。

    **使った数学**：オイラーの式（数III・複素数）、ベクトルの内積（線形代数I）、三平方の定理。

**FFT（高速フーリエ変換）**

DFTの計算量は $O(N^2)$。FFTはアルゴリズムの工夫により $O(N \log N)$ に短縮。

- $N = 1024$ なら DFT は約100万回の演算、FFTは約1万回
- Numpy の `np.fft.fft()` は自動的にFFTを使用

**PythonでFFTを計算してみよう**

```python
import numpy as np
import matplotlib.pyplot as plt

# サンプリング設定
fs = 44100       # サンプリング周波数（Hz）
duration = 0.1   # 信号の長さ（秒）
t = np.linspace(0, duration, int(fs * duration), endpoint=False)

# 440Hz と 880Hz のサイン波を合成
x = np.sin(2 * np.pi * 440 * t) + 0.5 * np.sin(2 * np.pi * 880 * t)

# FFTで周波数解析
X = np.fft.fft(x)
N = len(x)
freqs = np.fft.fftfreq(N, d=1/fs)

# 正の周波数だけ取り出す
positive = freqs > 0
plt.figure(figsize=(10, 4))
plt.plot(freqs[positive], np.abs(X[positive]))
plt.xlabel("周波数 (Hz)")
plt.ylabel("振幅")
plt.title("FFTによる周波数スペクトル（440Hz + 880Hz）")
plt.xlim(0, 2000)
plt.grid(True)
plt.tight_layout()
plt.show()
```

### スライド3: 短時間フーリエ変換（STFT）—なぜ「短時間」なのか

**問題点：FFTだけでは不十分**

FFTは「信号全体にどんな周波数が含まれているか」はわかりますが、「**いつ**その周波数が現れたか」はわかりません。

例：「あいうえお」という発話を分析する場合
- FFT：音声全体の周波数成分 → 「あ」「い」「う」「え」「お」が混在
- STFT：各時刻における周波数成分 → 「今この瞬間はどの母音か」がわかる

**STFTのアイデア**

$$
\text{STFT}\{x\}(m, k) = \sum_{n=0}^{N-1} x[n + mH] \cdot w[n] \cdot e^{-j\frac{2\pi}{N}kn}
$$

- $w[n]$：窓関数（後述）
- $m$：フレーム番号（時間位置）
- $H$：ホップサイズ（フレームをどれだけずらすか）
- $N$：フレーム長

**処理の流れ**

```
全音声信号
  ↓ 短い区間（フレーム）に切り出す（例：25ms）
フレーム1 → FFT → 周波数スペクトル1
フレーム2 → FFT → 周波数スペクトル2
フレーム3 → FFT → 周波数スペクトル3
  ...
  ↓ 横に並べる
スペクトログラム（時間 × 周波数の2次元マップ）
```

**フレーム長とホップサイズの設定例**

| パラメータ | 典型的な値 | 意味 |
|-----------|-----------|------|
| フレーム長 | 約25ms（44.1kHz なら 1,024サンプルで ≒23.2ms） | 各分析窓の長さ |
| ホップサイズ | 約10ms（44.1kHz なら 512サンプルで ≒11.6ms） | フレームのずらし幅 |
| オーバーラップ | 50〜75% | フレーム間の重複率 |

???+ note "導出②：窓を長くすると周波数は細かく、時間は粗くなる（核心）"

    導出①より、\( k \) 番目の成分が表す周波数は \( f_k = k f_s / N \) である。隣り合う \( k \) と \( k+1 \) の差を取ると、**この分析で見分けられる周波数の刻み**が出る。

    $$ \Delta f \;=\; f_{k+1} - f_k \;=\; \frac{f_s}{N} $$

    一方、\( N \) 点の窓が覆う時間の長さは

    $$ T \;=\; \frac{N}{f_s} $$

    である。この2つを掛けると、\( N \) も \( f_s \) も消える。

    $$ \Delta f \times T \;=\; \frac{f_s}{N} \times \frac{N}{f_s} \;=\; 1 \qquad\Longleftrightarrow\qquad \Delta f = \frac{1}{T} $$

    **周波数の細かさと時間の短さは、積が一定という形で結ばれている。** 片方をよくすれば、必ずもう片方が悪くなる。窓を長くして \( \Delta f \) を小さくすれば、その \( T \) 秒のあいだに起きたことは区別がつかなくなる。設定で調整できるのはトレードオフの**どこに立つか**だけで、両方を同時によくすることはできない。

    **数値で確かめる**（\( f_s = 16{,}000 \) Hz の場合）：

    | 窓長 \( T \) | 点数 \( N \) | 周波数の刻み \( \Delta f \) |
    |---|---:|---:|
    | 5 ms | 80 | 200.00 Hz |
    | 25 ms | 400 | 40.00 Hz |
    | 50 ms | 800 | 20.00 Hz |

    \( f_s = 44{,}100 \) Hz で \( N = 1024 \) なら \( \Delta f = 44{,}100 / 1024 = 43.07 \) Hz である。

    !!! note "短い窓と長い窓は、別のものを見せる"
        男性の声の基本周波数を 100 Hz とすると、倍音は 100 Hz 間隔に並ぶ。50 ms の窓（\( \Delta f = 20 \) Hz）なら倍音どうしを分けて見られるので、**横縞**として倍音が並ぶ。5 ms の窓（\( \Delta f = 200 \) Hz）では倍音は分けられないが、声帯が閉じるたびのパルスが時間軸で分かれて見えるので、**縦縞**が現れる。同じ音声でも、窓長を変えると違う模様になる。前者を狭帯域、後者を広帯域と呼ぶ。

    この「積が一定」という関係を、窓の形によらない一般の不確定性関係として厳密に述べるには、時間と周波数の広がりを分散で定義し直す必要がある。その定式化は、この授業で扱う数理の範囲外である。

    **使った数学**：導出①の \( f_k \) の式、単位の約分。

### スライド4: 窓関数の役割

**なぜ窓関数が必要か？**

フレームをそのまま切り出すと（矩形窓）、**端で信号が急に途切れる**ため、本来存在しない周波数成分（スペクトル漏れ）が発生します。

**スペクトル漏れ（Spectral Leakage）の問題**

```
矩形窓で切り出した場合：
  |────────────|    信号が端で急に0になる
  ↓FFT
  → 本来の周波数の周りに不要な成分が広がる（漏れ）
```

**窓関数：端をなだらかに0にする**

ハニング窓（Hann窓）：

$$
w[n] = 0.5 \left(1 - \cos\left(\frac{2\pi n}{N-1}\right)\right)
$$

その他の主な窓関数：

| 窓関数 | 特徴 | 用途 |
|--------|------|------|
| 矩形窓 | 漏れ大・分解能高 | 周波数が整数倍のとき |
| ハニング窓 | バランスが良い | 一般的な音声処理 |
| ハミング窓 | ハニングに近い | 音声処理（古典的） |
| ブラックマン窓 | 漏れ小・分解能低 | 精密スペクトル測定 |

???+ note "導出③：なぜ端を 0 にすると漏れが減るのか"

    DFT は \( N \) 点だけを見る。このとき裏側で何が起きているかというと、**その \( N \) 点が延々と繰り返されている信号**を分析したことになる。導出①の \( \boldsymbol{c}_k \) が \( N \) 点でちょうど整数周期になる波しか使っていないので、そうならざるをえない。

    すると、切り出した区間の**終わりと始まりがつながる**。ここで値が飛べば、元の信号にはなかった段差が生まれる。段差のような急な変化を余弦波と正弦波の和で表そうとすると、高い周波数まで多数の成分が必要になる。これがスペクトル漏れの正体である。

    表にある「矩形窓は周波数が整数倍のときに使う」も、ここから説明がつく。信号の周波数がちょうど \( f_k = k f_s/N \) に一致していれば、\( N \) 点は整数周期ぶんになり、端をつないでも段差が出ない。**そのときだけ矩形窓で漏れが出ない。**

    ハニング窓はこの段差を根元から断つ。上の式で両端の値を計算すると、

    $$ w[0] = 0.5\left(1 - \cos 0\right) = 0, \qquad w[N-1] = 0.5\left(1 - \cos 2\pi\right) = 0 $$

    どちらもちょうど 0 になる。窓を掛けた信号は端で必ず 0 なので、繰り返しても段差が生まれない。中央では \( n = (N-1)/2 \) のとき \( \cos\pi = -1 \) だから \( w = 1 \) で、信号をそのまま通す。

    ただし漏れは無料では消えない。窓を掛けることは信号を変形することなので、**1本の純音のピークが太くなる**。表の「漏れ小・分解能低」（ブラックマン窓）と「漏れ大・分解能高」（矩形窓）は、この代償の両端を言っている。窓の選択もまた、導出②と同じくトレードオフである。

    各窓のピークの太さや漏れの減り方を定量的に設計する議論は、この授業で扱う数理の範囲外である。

    **使った数学**：余弦関数の値（数II）、導出①の \( f_k \) の式。

**Pythonで窓関数を可視化**

```python
import numpy as np
import matplotlib.pyplot as plt

N = 64
n = np.arange(N)

# 各窓関数
rect   = np.ones(N)
hann   = 0.5 * (1 - np.cos(2 * np.pi * n / (N - 1)))
hamming = 0.54 - 0.46 * np.cos(2 * np.pi * n / (N - 1))

plt.figure(figsize=(10, 4))
plt.plot(rect,    label="矩形窓", linestyle='--')
plt.plot(hann,    label="ハニング窓")
plt.plot(hamming, label="ハミング窓")
plt.xlabel("サンプル番号")
plt.ylabel("重み")
plt.title("窓関数の比較")
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()
```

### スライド5: スペクトログラムの読み方

**スペクトログラムとは**

STFTの結果を**2次元カラーマップ**として可視化したもの。

```
縦軸（Y軸）：周波数（Hz）
  ↑高い音
  |
  |
  ↓低い音
  ─────────────────→ 横軸（X軸）：時間（秒）
  
色（濃さ）：そのフレーム・その周波数のエネルギー（強さ）
  明るい色（黄・白）→ 強い
  暗い色（紺・黒） → 弱い（またはない）
```

**スペクトログラムのスケール**

- 線形スケール：低音域が密集して見えにくい
- **対数スケール（dB）**：$10 \log_{10} |X[m,k]|^2$
  - 人間の聴覚に近い → 音声処理では常用

**デシベル（dB）とは**

$$
P_{dB} = 10 \log_{10} \frac{P}{P_{\text{ref}}}
$$

- 0dB：基準レベル
- 60dB：基準の100万倍のエネルギー
- -20dB：基準の1/100のエネルギー

### スライド6: 有声音・無声音・無音のスペクトログラムの違い

**3種類の音の特徴**

| 種類 | 例 | スペクトログラムの特徴 |
|------|----|-----------------------|
| 有声音 | あ・い・う・え・お・な・ま | 規則的な水平縞模様（調波構造） |
| 無声音 | さ・し・す・せ・そ・た・か | 高周波に広帯域のノイズ状成分 |
| 無音 | 発話の間 | 全体的に暗い（エネルギーほぼゼロ） |

**有声音の特徴：調波構造（Harmonic Structure）**

- **基本周波数（F0）**：声帯振動の周波数（男性100〜150Hz、女性200〜300Hz）
- **倍音（高調波）**：F0の整数倍（2F0, 3F0, 4F0, ...）に強いエネルギー
- スペクトログラムでは等間隔の水平縞に見える

```
周波数
  ↑
4F0 ─────────────  (倍音)
3F0 ─────────────  (倍音)
2F0 ─────────────  (倍音)
 F0 ─────────────  (基本周波数)
  ─────────────────────→ 時間
```

**無声音の特徴**

- 声帯振動なし → 調波構造がない
- 摩擦や破裂による**広帯域ノイズ**
- 例：「さ（/s/）」は3000Hz〜8000Hz に強いエネルギー

### スライド7: 日本語の母音「あいうえお」のスペクトログラム比較

**フォルマントとは**

声道（口や喉の形）により強調される周波数帯域を**フォルマント**といいます。

- **F1（第1フォルマント）**：口の開き具合に対応
- **F2（第2フォルマント）**：舌の前後位置に対応

**日本語母音のフォルマント周波数（目安）**

| 母音 | F1 (Hz) | F2 (Hz) | 口の形 |
|------|---------|---------|--------|
| あ /a/ | 800 | 1200 | 大きく開く |
| い /i/ | 300 | 2500 | 横に広げる |
| う /u/ | 400 | 1400 | 前に突き出す（やや） |
| え /e/ | 500 | 1900 | 中間 |
| お /o/ | 500 | 800 | 丸く突き出す |

**スペクトログラムで見分けるポイント**

- 「あ」：F1が高い（800Hz）→ スペクトログラムの低〜中域に強い縞
- 「い」：F2が非常に高い（2500Hz）→ 高域に明るい縞が見える
- 「お」：F2が低い（800Hz）→ 全体的に低域に集中

plt.ylabel("振幅")
plt.tight_layout()
plt.show()

```python
# ===== セル3：STFTを計算してスペクトログラムを描画 =====

# STFTのパラメータ
n_fft   = 2048   # FFT長（フレーム長）
hop_length = 512 # ホップサイズ（フレームのずらし幅）
window = 'hann'  # 窓関数

# STFTを計算
D = librosa.stft(y, n_fft=n_fft, hop_length=hop_length, window=window)
# D の形状：(n_fft/2 + 1, フレーム数) の複素数配列

# 振幅スペクトログラムをdBスケールに変換
S_db = librosa.amplitude_to_db(np.abs(D), ref=np.max)

print(f"スペクトログラムの形状: {S_db.shape}")
print(f"  周波数ビン数: {S_db.shape[0]}")
print(f"  フレーム数: {S_db.shape[1]}")

# 描画
fig, axes = plt.subplots(2, 1, figsize=(12, 8))

# 上段：線形スケール
S_linear = np.abs(D)
img1 = librosa.display.specshow(S_linear, sr=sr, hop_length=hop_length,
                                  x_axis='time', y_axis='hz', ax=axes[0])
axes[0].set_title("スペクトログラム（線形スケール）")
fig.colorbar(img1, ax=axes[0], format='%+.0f')

# 下段：対数スケール（dB）
img2 = librosa.display.specshow(S_db, sr=sr, hop_length=hop_length,
                                  x_axis='time', y_axis='log', ax=axes[1],
                                  cmap='magma')
axes[1].set_title("スペクトログラム（対数スケール、dB）")
fig.colorbar(img2, ax=axes[1], format='%+.0f dB')

plt.tight_layout()
plt.show()
```

```python
# ===== セル4：母音「あいうえお」のスペクトログラム比較 =====
# ※ここでは合成音声でシミュレート（実際の授業では録音データを使用）

import numpy as np
import matplotlib.pyplot as plt

def make_vowel(f0, formants, duration=0.5, sr=22050):
    """
    シンプルな合成母音を生成する関数
    f0: 基本周波数（Hz）
    formants: フォルマント周波数のリスト [F1, F2, F3]
    """
    t = np.linspace(0, duration, int(sr * duration), endpoint=False)
    # 基音 + 倍音
    signal = np.zeros_like(t)
    for k in range(1, 10):  # 1〜9倍音
        signal += (1.0 / k) * np.sin(2 * np.pi * f0 * k * t)
    # フォルマントでフィルタリング（簡易版：周波数付近を強調）
    # ここでは各フォルマント付近のサイン波を加算して近似
    for f_form in formants:
        signal += 0.5 * np.sin(2 * np.pi * f_form * t)
    # 正規化
    signal = signal / np.max(np.abs(signal))
    return signal

# 母音ごとのフォルマント（概略値）
vowels = {
    'あ (a)': [800, 1200, 2600],
    'い (i)': [300, 2500, 3200],
    'う (u)': [400, 1400, 2400],
    'え (e)': [500, 1900, 2700],
    'お (o)': [500,  800, 2400],
}

f0 = 150   # 基本周波数（女性声を想定）
sr = 22050
n_fft = 1024
hop_length = 256

fig, axes = plt.subplots(2, 5, figsize=(18, 8))

for col, (vowel_name, formants) in enumerate(vowels.items()):
    signal = make_vowel(f0, formants, duration=0.5, sr=sr)

    # 波形
    axes[0, col].plot(np.linspace(0, 0.5, len(signal)), signal, linewidth=0.5)
    axes[0, col].set_title(f"波形\n{vowel_name}", fontsize=10)
    axes[0, col].set_xlabel("時間 (秒)")
    axes[0, col].set_xlim(0, 0.5)
    if col == 0:
        axes[0, col].set_ylabel("振幅")

    # スペクトログラム
    D = librosa.stft(signal, n_fft=n_fft, hop_length=hop_length)
    S_db = librosa.amplitude_to_db(np.abs(D), ref=np.max)
    img = librosa.display.specshow(S_db, sr=sr, hop_length=hop_length,
                                    x_axis='time', y_axis='hz',
                                    ax=axes[1, col], cmap='magma')
    axes[1, col].set_title(f"スペクトログラム\n{vowel_name}", fontsize=10)
    axes[1, col].set_ylim(0, 5000)

fig.suptitle("日本語母音「あいうえお」のスペクトログラム比較（合成音声）", fontsize=13)
plt.tight_layout()
plt.show()
```

# Google Colab での音声録音

from google.colab import output
from IPython.display import Javascript
import base64
import io

# JavaScriptで録音するためのコード
record_js = """
async function recordAudio() {
  const stream = await navigator.mediaDevices.getUserMedia({audio: true});
  const recorder = new MediaRecorder(stream);
  const chunks = [];
  
  return new Promise((resolve) => {
    recorder.ondataavailable = e => chunks.push(e.data);
    recorder.onstop = () => {
      const blob = new Blob(chunks, {type: 'audio/webm'});
      const reader = new FileReader();
      reader.onloadend = () => resolve(reader.result);
      reader.readAsDataURL(blob);
    };
    
    recorder.start();
    setTimeout(() => {
      recorder.stop();
      stream.getTracks().forEach(t => t.stop());
    }, 3000);  // 3秒録音
  });
}

const result = await recordAudio();
google.colab.kernel.invokeFunction('notebook.set_audio', [result], {});
"""

# 録音データを受け取るコールバック
recorded_audio = {}

def set_audio(audio_data):
    recorded_audio['data'] = audio_data
    print("録音完了！")

output.register_callback('notebook.set_audio', set_audio)
display(Javascript(record_js))
print("3秒間、何か話してください（「あいうえお」など）...")

### スライド10: まとめと次回予告

**本日のまとめ**

| 概念 | ポイント |
|------|----------|
| フーリエ変換 | 音 = サイン波の重ね合わせ。FFTで効率的に計算 |
| STFT | 「短時間」ごとにFFT → 時間変化を追える |
| 窓関数 | スペクトル漏れを防ぐ。ハニング窓が定番 |
| スペクトログラム | 横=時間、縦=周波数、色=強度の2次元マップ |
| 有声音 | 等間隔の調波構造（縞模様） |
| 無声音 | 高域に広帯域ノイズ |

**次回（第5回・動画回）予告：MFCC**

> スペクトログラムの情報を人間の聴覚特性に合わせて圧縮する。
> これが音声認識の最重要特徴量 MFCC です！

    音声処理と認識¶

    北星学園大学 情報科学部 情報科学科　3年後期・2単位　／　担当：小野原 彩香

    この授業について¶

    人間の発話音声をデジタル信号として処理・分析する代表的な方法を習得し、音声認識技術の基礎を理解します。

    前半では音の性質やヒトの発話・聴覚のしくみを概観し、音声信号のデジタル処理（スペクトログラム、MFCC など）を学びます。後半では、機械学習による音声認識や、音声インタフェースの実例（Siri、Google 音声入力など）を取り上げ、自然言語処理・AI 技術との接続にも触れます。統計的手法とともに、音声と認知・言語との関連にも意識を向け、文理融合的な視点から音声技術の基礎を身につけます。

    講義と Python 演習（Google Colab）を組み合わせて進めます。半数の回はオンデマンド動画＋CBT（理解確認テスト）、残りはオンライン同期型で実施します。

    神経多様性への配慮

    発話・録音・発表・対人作業が困難な場合には、事前に相談のうえで代替手段を設けます。評価の形式にも幅を持たせています。同じ内容を、視覚教材・聴覚教材・テキスト教材の3通りで用意します。

    各回に「進化の視点」があります

    ヒトの声と耳は、設計されたのではなく進化してできた器官です。各回に、その回の技術とつながる進化・生物学の話を1つずつ置いています。第1回と第14回で、全体をこの視点から振り返ります。

    到達目標¶

    1. 音声をデジタル信号として分析するための基本的手法を説明できる
    2. 音響特徴量（MFCC など）を用いた音声データの解析ができる
    3. 音声認識技術の基礎構成と仕組みを説明できる
    4. Python で簡単な音声処理ができる
    5. 音声処理と認知・言語・UX 設計との関係を論じられる

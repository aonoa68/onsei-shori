    学習目標¶

    この回を終えると、次のことができるようになる：

    1. この授業の全体構成・評価方法・受講ルールを説明できる
    2. 音声技術がどのような製品・サービスに使われているかを具体的に挙げられる
    3. 音声処理の大まかなパイプライン（流れ）をステップ順に説明できる
    4. この授業で「学ぶこと」と「学ばないこと」を区別できる

    このコースの資料は、視覚的な説明（図・図解の文字説明）とテキスト説明を常に両方用意しています。動画は字幕付きで提供します。自分に合ったペースで取り組んでください。

    進化の視点：音声技術は、進化が作った装置の再実装である¶

    ヒトの声と耳は、設計されたのではなく進化してできた器官である。この授業で扱う技術は、その器官が作る信号を機械で受け取り、器官の分解能に合わせて表現し直し、器官がしている判断を模倣しようとする試みだ。

    • 収音とデジタル化は、鼓膜と蝸牛がしている変換の代わりである（第3回・第4回）
    • MFCC は、蝸牛の周波数分解の非線形性をまねた特徴量である（第5回）
    • 音声認識は、ヒトが雑音の中で声を聞き分ける働きを機械で置き換えようとしている（第9回）

    この授業の問い：どこまでがヒトの模倣で、どこからが模倣をやめた方が良い設計なのか。各回の「進化の視点」で少しずつ考える。

    各ステップの説明: 1. 収音: マイクロフォンが空気の振動（音波）を電気信号に変換 2. デジタル化: アナログ電気信号を数値の列（デジタル信号）に変換（第3回で詳しく） 3. 特徴抽出: 音声の「特徴量」（MFCCなど）を計算（第5回で詳しく） 4. 認識・理解: 特徴量から文字・単語・意味を推定（第7〜9回で詳しく） 5. 応用: 認識結果を使ったアプリケーション（第13〜14回で詳しく）

    スライド10: 音声認識の精度はどこまで来たか¶

    タイトル: 現在の音声認識技術の水準

    表示内容: - 単語誤り率（WER）: 音声認識の精度指標 - WER = （誤認識単語数 ÷ 総単語数）× 100% - 例：「今日はいい天気です」5単語のうち1単語を間違えた → WER = 20%

    • 精度の推移（英語・電話音声の場合）:
    年代 WER
    1990年代 〜40%
    2010年前後 〜15%
    2016年（深層学習導入後） 〜5%
    現在（Whisperなど） 〜3%（クリーン環境）
    • ただし: ノイズ環境・方言・専門用語では精度が大きく低下する

    講師メモ: 「人間の転写ミス率は約4〜5%と言われており、最新のAIはほぼ人間並みになっている分野もある」という話を加える。

    テスト問題（5問・4択・解答解説付き、Google Formsで回答）¶

    問1¶

    音声処理パイプラインの順序として正しいものはどれか。

    A) 特徴抽出 → 収音 → デジタル化 → 認識 → 応用 B) 収音 → デジタル化 → 特徴抽出 → 認識 → 応用 C) デジタル化 → 収音 → 特徴抽出 → 応用 → 認識 D) 収音 → 特徴抽出 → デジタル化 → 認識 → 応用

    正解: B

    解説: 音声処理は、まずマイクで音を拾い（収音）、アナログ信号を数値に変換し（デジタル化）、その数値から音声の特徴を計算し（特徴抽出）、特徴量から意味を推定し（認識）、最終的に利用者向けのサービスに使われる（応用）という順序で処理される。特徴抽出はデジタル化の後でなければ行えないため、A・C・Dは誤り。

    問2¶

    単語誤り率（WER: Word Error Rate）が20%であるとき、100単語の発話に対して何単語が誤認識されていると考えられるか。

    A) 2単語 B) 10単語 C) 20単語 D) 80単語

    正解: C

    解説: WER = 誤認識単語数 ÷ 総単語数 × 100%。 WER = 20% の場合、誤認識単語数 = 100単語 × 20% = 20単語。 Dの80単語は「正認識された単語数」であり、誤りと正解を混同した誤答。

    問3¶

    以下の音声技術の応用例のうち、「テキスト音声合成（TTS: Text-to-Speech）」に分類されるものはどれか。

    A) Alexa がユーザーの「音楽をかけて」という声を聞き取る B) カーナビが「次の交差点を右折してください」と音声で案内する C) Zoom が会議の会話を自動的に文字に起こす D) スマートフォンのウェイクワード検出機能が「Hey Siri」を認識する

    正解: B

    解説: テキスト音声合成（TTS）は「テキスト（文字）→ 音声」の変換。カーナビはあらかじめ用意されたテキストを音声に変換して読み上げる。A・Dは音声認識（音声→テキスト/コマンド）、CはASR（自動音声認識）に該当する。

    問4¶

    音声処理技術の「バイアス問題」として最も適切に説明しているものはどれか。

    A) 音声認識システムは処理速度が遅いため、リアルタイムには使えない B) 特定の方言や話し方に対して認識精度が低くなるなど、公平でない性能差が生じる C) 音声データはファイルサイズが大きいため、保存コストがかかる D) 音声認識は静かな環境でしか使えない

    正解: B

    解説: 音声認識システムのバイアス問題とは、学習データが特定の話者特性（標準的なアクセント・成人男性の声など）に偏っている場合、その特性に当てはまらない人（方言話者・子ども・高齢者など）に対して精度が著しく低下する現象。これは公平性（Fairness）の観点から重要な倫理的課題。A・C・Dは正確だが「バイアス問題」の説明としては不適切。

    問5¶

    この授業の評価方法として正しい説明はどれか。

    A) テストと期末試験はそれぞれ50%ずつで合計100% B) テストは一度しか受験できず、その点数が記録される C) テストが30%、期末試験が70%で合計100%であり、テストは繰り返し受験可能 D) 出席点が20%、テストが30%、期末試験が50%で合計100%

    正解: C

    解説: 評価内訳はテスト30%・期末試験70%。テストは締め切りまでに何度でも受験可能で、最高点が採用される。出席点は設定されていない。Bのような「一度きり」という制約はなく、繰り返し学習を促す設計になっている。

    事前学習（第2回「発話・聴覚メカニズム」の準備）¶

    第2回はオンライン同期形式で、ヒトが声を出し聴く仕組みを扱います。以下の事前学習に取り組んでおくことで、授業への参加の質が高まります（所要時間：合計15〜20分）。

    1. 自分の声を録音して聴いてみる¶

    スマートフォンのボイスメモアプリや録音アプリを使い、10〜15秒程度の発話を録音し、聴き直してみる。

    考えてみること: 自分の録音した声は、普段耳にしている「自分の声」と同じに聞こえるか？違うとしたら、なぜそう感じると思うか？

    （ヒント：骨伝導と空気伝導の違いに関係がある）

    2. マクガーク効果の動画を見る¶

    YouTube で「マクガーク効果（McGurk effect）」を検索して、代表的な実験動画を1〜2本視聴する。

    考えてみること: この現象は何を意味しているか？音声は「耳だけ」で聴かれているのか？

    3. カクテルパーティ効果について調べる¶

    「カクテルパーティ効果」とは何かを調べ、自分の言葉で1〜2文でまとめておく。

    考えてみること: 機械（音声認識システム）にとって、カクテルパーティ効果の再現はなぜ難しいと思うか？
